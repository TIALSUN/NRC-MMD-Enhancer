# 动作、穿模、装机与交付

## 验证流程

同 PMX/VMD、同帧同镜头做物理开/关对照。袖口露肤查装配、缝边、四权重和扭转；手臂穿胸前衣服查体型与动作接触姿势；活动衣料查动态骨、碰撞与刚体。通用规则进入转换器，舞蹈专属修正另存 VMD，保留原动作。

距离、BVH 和相交用于定位候选，结合部位、材质和正侧背画面判断。骨骼/几何数值有限不代表没有穿模，不用放大碰撞体代替蒙皮修正。

1. 文件解析：骨索引、父级、轴、IK/D、Morph 合法，非零权重最多四个且归一化，贴图相对路径存在。显式服装、妆容、附加骨确实写入。
2. 干净场景重开最终 PMX，载入真实 VMD，30fps。核对活动骨和 Morph 轨匹配且有非零驱动；静态表情用例补足动作未覆盖项。
3. 完整帧段检查活动骨数值，采样几何范围；闭眼、最大开口、接触极值帧正侧背特写。视频检查帧数、fps、时长与解码。抽样数值通过不能替代逐件视觉。
4. 物理从静止和缓冲帧起算，删缓存后重烘焙；回读 PMX 刚体、关节、绑定骨与碰撞位，检查实际衣料和头发的连续跳变。详见 physics.md。
5. 全量清单按配置条目与去重几何分别计数，共用/变体建立映射。缺资源、结构通过、效果待复核、视觉通过分开统计；眼型列出已测表情和视线用例。

代表回归：PC1/PC2 默认、PC2 连衣、两性头饰、用户固定预设。IRIS OUT 样例原 0—464 帧，30 帧缓冲后活动段 31—495，共 465 帧/30fps/15.5 秒；其他动作重新算帧映射。

## 装机和交付

从当前安装版提取 app，记录 SHA256。打包核对差异与新增资源，保留累计功能；安装前复核当前哈希并备份。实际运行服务重新导出，审计 PMX、贴图及 report 修订标记，不能以候选包测试代替装机测试。

公开或跨机器发布时，ZIP 只放程序代码、技能、获取清单和第三方打包工具；游戏模型、贴图、解码表、Morph 兼容 GLB、着色器与 Pak 必须由技能从用户本机当前客户端生成。代码覆盖层应从用户已有 NRC 基础包继承本地运行时资源，不能把生成后的含资源 ASAR 放进发布 ZIP。压缩包审计同时检查扩展名和可疑文件名，不能只看顶层目录。

交付 PMX+Tex+report，按任务附 VMD、对照图、视频和可重开 blend。贴图 pack，保存重开确认缓存 baked。ZIP 校验 CRC 和文件哈希，记录输入、转换器、安装包、动作和模型哈希、适用范围及剩余问题。

Blender/MMD Tools 与 MikuMikuDance.exe 分开报告。无光照原贴图画面用于几何检查，不作为游戏 shader/MME 复刻证据。公开分享保留动作来源与适用许可信息。

## 运行时定位

每次执行先运行 `scripts/detect-runtime.ps1`，从 FModel 设置、常见安装位置和 NRC 配置生成 `runtime.json`。不要使用技能中的历史盘符、用户名、输出目录或装机哈希替代当前环境。

需要找到：

- 当前 NRC 安装的 `resources/app.asar`、配置根和备份列表。
- Blender 可执行文件及 MMD Tools 扩展。
- 当前客户端、CUE4Parse/FModel、Detex、解码器和 Schema。
- 用户已有的当前版模型、贴图、配置、Morph 兼容资源和动作目录。

当前代码覆盖层包含统一“导出 MMD”入口、服装骨摘要、原生衣料物理和 WeiBa 稳定性策略。安装前记录基础与候选 ASAR 哈希，备份只增不删。

历史覆盖统计、动作样本和验证结果只能作为测试选择依据；当前客户端、当前装机版和实际导出报告才是验收依据。Blender/MMD Tools 与 MikuMikuDance.exe 始终分开报告。
