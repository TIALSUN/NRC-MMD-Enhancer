# 可选项兼容性普查与规则（2026-10-22）

全量核对可选项与导出器规则，定位“选择无效、导出失败、发帽互穿”等问题，并把通用规则沉到转换器。库存与报告只在开发工作区，不随仓库发布（避免包含游戏数据）。

- 物品 1724 件、沙龙 346 项、套装 256 套、导出库反向缺口 157 个网格目录。
- 静态：按安装版导出器规则复刻解析，与 142 份真实导出报告的 2061 条“材质→贴图”绑定交叉验证，0 不一致。

- 动作：IRIS OUT.vmd 500 帧 × 代表模型，验证骨/表情覆盖、物理与形变（scripts/vmd-motion-test.py）。

## 物品解析规则

- 找不到网格但配置存在：抛 `ItemMeshMissing`，`resolve_requested_items` 捕获后记入 `items_skipped`（含原因），不中断整次导出。
- 变体/异色：配置 id 查不到网格时按几何 id 回退；合并前按 asset_id 改名材质，贴图按新名字查。
- 性别：物品 gender ∈ {1,2} 与导出角色不一致时跳过并记录“性别不匹配”；包挂饰/法杖等 gender 3 不受限。
- 类型与槽位：以实际网格槽位为准。`type_name=帽子` 但网格在 `Hi` 槽时按头饰处理（tokens 用 Hi，report 记 `reclassified_from="帽子"`、`mesh_slot`）。当前只有 12108501 命中：名称、女款 22108501、资源与 HEADWEAR 数据都表明它是静态头饰；强行按帽子切 Ht 发型会悬空（基础发型偏移）或掉到脖子（Ht 偏移全 0）。
- 全量核对 1724 件里“名称前缀 ≠ type_name”只有 12108501 一件；167 件帽子里只有它是静态 SM/Hi，其余 163 件都是蒙皮 SKM/Ht。

## 沙龙与外观

- 肤色：`3000000N` 推导脸皮/身体贴图（PC1 base 10000000、PC2 base 20000000；et = base+400000+N，by = base+N），缺图才回退默认并写 `skin_fallback`。
- 发色：先查 `T_<角色>_Hr_<基础ID>_<色号>_D.png`；文件名不规范时读取该色号材质 `MI_<角色>_Hr_<编号>.props.txt` 的 BaseTex 反查。
- 眼型：按性别 avatar→model 组合 Fe/Et/Es/Er；6/22 复用同一脸皮贴图属正常。
- 眉形：50 个沙龙眉形未接线（导出器没有 --brow-avatar-id），颜色通道正常；资源库有 18 个眉形网格可作后续实现依据，但缺游戏内对照，默认启用会改变默认眉形，暂不开启。

## 头部饰品与帽子

- 面饰/口罩/头套（Fi/Ms/Hg/Hp）与静态头饰（Hi）挂 `Bip001-Head`，不借用“当前发型无头饰(WearType0)”偏移，避免位置随发型/性别漂移；Fi/Hi 另做 ≤8mm 前向 clearance。
- 帽子/头饰摆放：`HEADWEAR_HAIR_CONF` 的 WearType 偏移只对基础发型（`SKM_*_Hr_*`）有定义；`HEADWEAR_OFFSET_CONF` 的 1414 条配对里 0 条引用 Ht 发型。因此头饰/静态帽子按基础发型查表，不切 Ht 发型；普通蒙皮帽子（SKM/Ht）走骨权重，不受影响。
- 12108501 修复前后几何一致（verts 14337→14337、材质数不变），只改语义与 report；这是有意的：游戏数据不支持切戴帽发型，硬切会悬空或掉脖子。

## 已知限制

- `*_Op` 半透明壳（7 件）：游戏侧是半透明材质，PMX 没有混合模式；方框眼镜镜片的外观用户已确认保持原样。改成跳过或统一透明都会破坏已确认外观，暂不处理。
- 眉形 50 项：见上，未接线。
- “帽子 / 头饰”的 UI 互斥与分类仍按游戏 type_name；只有导出器按网格槽位纠正。
- 未实装 7 套：现在不再导致导出失败，但缺那几件部件（游戏未实装，预期行为）。
- 157 个反向缺口：未上架/废案资源，不影响当前导出。

## 复现与验收

1. 静态：用当前安装版 `mmd/roco-to-mmd.py` 的解析规则扫描 `FASHION_ITEM_CONF` / `FASHION_SALON_CONF` / `FASHION_SUITS_CONF`，对照网格索引与 HEADWEAR 三表；规则变化后重跑并抽查 20 件以上真实导出报告。
2. 动态：按部位类型与性别抽样走 NRC `POST /api/mmd/export`，检查 report 的 items/items_skipped/textures_unbound/physics 与 `pmx_sha256`。
3. PMX 回读：`python scripts/pmx_verify.py <pmx> --report <report.json>`，要求 0 fail；warn 逐条确认原因。
4. 动作：`blender -b -noaudio --factory-startup --python scripts/vmd-motion-test.py -- --pmx <pmx> --vmd <vmd> --out <dir> --png`，检查骨/表情覆盖、物理刚体数、无 NaN 与采样帧渲染。
