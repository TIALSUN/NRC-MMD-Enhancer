## 密钥来源与使用

客户端资源重新挂载、补导 Morph 或贴图时才需要 AES；已有 PMX/GLB 的转换与动作验证不需要重新取密钥。

- 已确认来源：用户在对话 `01a13e0f-bc9a-7f92-b6ad-f603f2ac8416`（“适配MMD并保留炫彩效果”）中提供，位于讨论“让模型跳舞时有表情”和查找 GitHub 方案之后。按该对话 ID 读取用户原消息；不要用助手转述或截断片段拼接。
- 项目早期解包来源还可查 `conversation-evidence/` 中原始项目对话记录；优先使用上述明确确认的消息。历史密钥只对应当时客户端，新版本须以实际挂载结果确认仍适用。
- 脚本读取当前进程环境变量 `NRC_AES`。相关入口：`work/mmd-morph/cue-export-meshes-morph.ps1`、`workflow-tools/cue-list-index.ps1`、`workflow-tools/cue-export-meshes.ps1`、`workflow-tools/cue-export-textures.ps1`。
- 仅在内存中取得并传入运行进程；可检查去掉可选 `0x` 前缀后是否为 64 位十六进制，但不输出内容。不要把值写入 skill、脚本、配置、命令记录、日志、报告或交付包。记录来源对话 ID、环境变量名和挂载验收结果即可。
- 没有环境变量且无法访问原消息时，说明缺少运行输入并请用户提供；不要把历史引用当成已成功取到密钥。按完整索引验收挂载，不以脚本无报错或部分导出成功认定密钥正确。

## 装配

从当前选择或选装 JSON 解析性别、服装、妆容、发色、眉色和炫彩。空服装列表按默认槽位装配，允许直接导出。默认发色与眉色沿用用户确认的初始棕色预设，实际选择优先。

- 全身网格含默认装。穿衣模式保留所需头部组件，Cup/Ps/So/Se/Ge/Bg 身体六槽使用对应部件及其露肤补片；不能再垫整块裸身皮肤，也不能统一删除 By。
- 用 `FASHION_ITEM_CONF` 槽位、上下装标签判断替换与互斥。默认占位和 salon 条目通过各自配置解析，不当成普通服装 ID。
- 眼型按性别的 avatar→model 映射组合 Fe/Et/Es/Er，替换时移除旧组件和材质。眉毛、瞳孔、面妆、肤色独立处理。
- 戴帽发型、头饰挂点及偏移用 `HEADWEAR_HAIR_CONF`；共用款、变体、头套和静态饰品按实际引用与坐标规则定位。目录不存在时先核对共用资源。
- 服装合并前保留缺失加权骨及其祖先，统一骨架与网格空间后重定向。身体无权重不代表服装或动画不需要该骨。只处理真实网格，排除骨骼显示几何。
- 显式请求的衣服必须进入最终 PMX；缺资源报告缺口，不静默换默认款冒充成功。

## 转换与材质

沿用当前累计转换器的标准日文骨名、层级、扭转、足 IK/D/EX、表示枠、表情与物理。保持静止网格和骨架一致，沿用当前 A 姿态规则，不统一强转 T 姿态。按实际高度和目标单位决定缩放，避免重复换算。

PMX 最多四个非零骨权重。身体与衣服采用协调的扭转场，合并重复影响、限制预算并归一化；审计最终 PMX 确认导出器未截掉影响，不以统一双权重代替合法四权重。

按材质实例解析共享眉毛、PupilTex/BaseTex 等贴图。瞳孔保持原 UV 和图像布局；面妆按透明度叠合，发色眉色随选择。脸部色差先查顶点色乘法、金属度和法线。`_Im`/`_Op` 特效材质单列复核，不能一概当 diffuse 缺失或统一透明化。

炫彩按需静态烘焙到新贴图，保留原图并避免同名覆盖。静态 PMX 不执行游戏流动、闪粉、折射、材质通知；动态效果需另做 Blender 材质或 MME。追加 UV 最多四组，顶点色无直接对应字段，记录实际取舍。

统一“导出 MMD”按钮自动读取当前炫彩选择：原色输出 PMX/普通贴图，炫彩同时输出 PMX、炫彩参数/贴图与打包资源的动态 .blend。具体使用与验证范围见 [dynamic-chroma.md](dynamic-chroma.md)。静态烘焙加 `--tex-override` 仍可用于独立 PMX。

## NRC

沿用“导出 MMD”按钮，每次独立目录包含 `<名称>.pmx`、`Tex/`、`<名称>.report.json`。空选择、当前妆容、发色眉色与眼型都走同一链路。

接口：`POST /api/mmd/export` 创建 job，`GET /api/mmd/export/:id` 查询，`POST /api/mmd/reveal` 打开目录。请求字段先查当前 server.js。设置含 `mmdBlender`、`mmdOutDir`、`mmdMorphRoot`、`mmdNaming`、`mmdPhysics`；随包工具释放到输出目录 `.mmd-tools/`。

导出衣服时保留服装实际使用的骨骼、父级和顶点权重。转换 report 写 `clothing_bones_summary.weighted/added`；NRC 完成任务的 `result.boneSummary` 同时返回骨骼总数、保留权重骨数、服装权重骨清单和服装新增骨清单，界面完成提示显示“骨骼 / 服装骨 / 新增”。该摘要来自 Blender 实际转换报告，不是前端估算。

修改从当前安装版提取 app，保留累计功能；新资源同步加入 `MMD_TOOL_FILES`。验证空选择、显式服装、眼型、妆容、输出隔离与缺失资源报告。候选通过后仍需实际安装服务导出，见 validation-delivery.md。
